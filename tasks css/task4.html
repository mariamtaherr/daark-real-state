Frequently asked

How much time should I set aside each week?

We recommend around 10-15 hours per week to complete the projects and lessons.

Do I need experience before starting?

Basic knowledge of HTML and CSS is helpful, but we cover all core concepts from scratch.

How is the final project reviewed?

Each project gets personalized feedback and line-by-line code review from a senior developer.

Can I pause a cohort and rejoin later?

Yes, you can pause your progress and jump back into the next upcoming cohort anytime.
